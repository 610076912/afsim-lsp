# osm_traffic

**Script Class:** `WsfOSM_Traffic`

## Overview

The `osm_traffic` block generates background road traffic on a predefined `route_network`, similar to `road_traffic`, but specifically designed for networks generated by Wizard's OSM Converter Tool.

It can use `route.aux_data` and waypoint aux data to model speed limits, stop signs, traffic lights, lane counts, one-way roads, and related rules of the road.

## Syntax

```wsf
osm_traffic
   debug <boolean-value>
   network <route-network-name>
      vehicle_count <positive-integer>
      maximum_speed <speed-value>

      vehicle <platform-type>
         fraction <real-value>
         mean_speed <speed-value>
         sigma_speed <speed-value>
         ignore_speed_limits
      end_vehicle

      route_aux_data_mapping
         minimum_speed <string>
         maximum_speed <string>
         lanes <string>
         one_way <string>
         density <string>
         surface <string>
      end_route_aux_data_mapping

      waypoint_aux_data_mapping
         stop <string>
         traffic_signals <string>
         highway <string>
      end_waypoint_aux_data_mapping
   end_network
end_osm_traffic
```

## Commands

### debug

**Syntax:** `debug <boolean-value>`

Enables or disables debugging output to standard output.

### network ... end_network

Defines the attributes and vehicles generated on the named `route_network`.

### vehicle_count

**Syntax:** `vehicle_count <positive-integer>`

### maximum_speed

**Syntax:** `maximum_speed <speed-value>`

### vehicle ... end_vehicle

Defines a specific vehicle type within the network.

#### fraction

**Syntax:** `fraction <real-value>`

#### mean_speed

**Syntax:** `mean_speed <speed-value>`

#### sigma_speed

**Syntax:** `sigma_speed <speed-value>`

#### ignore_speed_limits

**Syntax:** `ignore_speed_limits`

### route_aux_data_mapping ... end_route_aux_data_mapping

Maps route aux-data variable names to OSM traffic behavior fields.

#### minimum_speed

**Syntax:** `minimum_speed <aux-data-variable-name>`

#### maximum_speed

**Syntax:** `maximum_speed <aux-data-variable-name>`

#### lanes

**Syntax:** `lanes <aux-data-variable-name>`

#### one_way

**Syntax:** `one_way <aux-data-variable-name>`

#### density

**Syntax:** `density <aux-data-variable-name>`

#### surface

**Syntax:** `surface <aux-data-variable-name>`

### waypoint_aux_data_mapping ... end_waypoint_aux_data_mapping

Maps waypoint aux-data variable names to stop/traffic-control behavior.

#### stop

**Syntax:** `stop <aux-data-variable-name>`

#### traffic_signals

**Syntax:** `traffic_signals <aux-data-variable-name>`

#### highway

**Syntax:** `highway <aux-data-variable-name>`

## Notes

- `osm_traffic` internally modifies route naming to represent segments, direction, and lane structure.
- It is also compatible with scripted vehicles, as long as the associated road/traffic commands are used consistently.
